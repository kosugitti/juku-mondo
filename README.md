# 塾Q&A

勉強会・合宿の発表中に，参加者が質問やコメントを書き込む掲示板。Sli.do の質問板に「返信」を足したもの。

- 参加者は匿名で入り，表示名(マスコットネーム)は任意
- 投稿・返信・いいね・新しい順/古い順/いいね順の並べ替え
- 各自が CSV(Excel で開ける UTF-8)で保存できる
- イベントごとに別の URL。新しいイベントを作れるのは許可リストの幹事だけ
- 司会(イベント作成者と幹事)は非表示・受付の締め切り・イベント削除・QRコード表示ができる

構成は Firebase(Hosting + Firestore + Authentication)。サーバは持たない。

| ファイル | 中身 |
|---|---|
| `public/` | 画面(index.html・app.js・style.css)。これがそのまま公開される |
| `firestore.rules` | 誰が何を読み書きできるか。守りはここだけが担う |
| `tests/rules.test.mjs` | ルールの自動テスト |
| `scripts/dev.sh` | 手元の模擬環境(エミュレータ)を起動 |
| `scripts/seed-emulator.sh` | 模擬環境に幹事の許可リストを入れる |

## 初回の準備(1回だけ)

### 1. Firebase プロジェクトを作る(ブラウザ)

1. https://console.firebase.google.com/ を organizer@example.com で開き，「プロジェクトを作成」。名前は `juku-qa` など。Google アナリティクスはオフでよい。
2. 左の「構築 > Authentication」で「始める」。「ログイン方法」タブで次の2つを有効にする。
   - 匿名
   - Google(サポートメールに自分のアドレスを選ぶ)
3. 「構築 > Firestore Database」で「データベースを作成」。ロケーションは `asia-northeast1 (Tokyo)`，モードは「本番環境モード」。
4. 歯車 > 「プロジェクトの設定」>「マイアプリ」で，`</>`(ウェブ)のアプリを追加する。名前は何でもよい。表示される設定値は控えなくてよい(Hosting が自動で配る)。
5. (推奨)左下の「アップグレード」から Blaze プランにし，予算アラートを月500円などで設定する。無料枠は Blaze でもそのまま使え，超えた分だけ課金される。Spark のままだと上限に達した日にアプリが止まる。

### 2. 幹事の許可リストを作る(ブラウザ)

Firestore Database の「データ」タブで「コレクションを開始」。

- コレクションID: `config`
- ドキュメントID: `organizers`
- フィールド: `emails`，型は array，値に幹事の Gmail アドレス(string)を並べる

幹事の追加・削除は以後この配列を書き換えるだけ。再デプロイは要らない。

### 3. 手元とプロジェクトを結びつける(ターミナル)

```sh
firebase login          # ブラウザが開くので Google でログイン
cd juku-qa
firebase use --add      # 作ったプロジェクトを選び，別名は default
```

`.firebaserc` ができる。これはコミットしてよい(秘密情報は入っていない)。

### 4. 公開する

```sh
firebase deploy
```

画面とルールが上がり，`https://<プロジェクトID>.web.app` で開ける。

## 使い方

1. 幹事がトップページで「幹事としてGoogleでログイン」し，イベント名を入れて「作成」。
2. 開いたイベント画面の「URLをコピー」か「QRコード」で参加者に配る。
3. 終わったら「受付を締め切る」。参加者はその後も閲覧と CSV 保存ができる。
4. 全員が保存し終えたら「イベントを削除」。削除しなくても困らない。

## 直したあとの確認

```sh
scripts/dev.sh                     # 模擬環境を起動(Java は Homebrew の openjdk@21)
scripts/seed-emulator.sh           # 別ターミナルで。幹事リストを入れる
open http://127.0.0.1:5050         # 画面
cd tests && npm install && npm test  # ルールのテスト(模擬環境のデータは消える)
```

模擬環境は本番に一切触れない。`localhost` で開くとアプリが自動で模擬環境につなぐ。

## 費用の目安

50人が1日中使う回で，読み取りが1日4〜5万回。Firestore の無料枠(1日5万回)の上限近くになる。超過分は10万回あたり数十円程度。
